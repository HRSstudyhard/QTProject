# 实验一：带键盘事件的计算器（Qt / C++）

东莞理工学院 计算机科学与技术学院 实验一作业。
用 Qt Widgets 实现的四则运算计算器，支持鼠标按键与键盘输入，二者复用同一套处理逻辑。

## 功能

- 四则运算（+ - × ÷）、小数输入、退格、CE（清除当前输入）、C（全部清除）、±（正负号）
- 一元运算：%（百分号）、1/x（倒数）、x^2（平方）、√（开方）
- 状态栏实时显示当前运算符、计算结果与错误提示，显示框上方显示“左操作数 + 运算符”
- 边界处理：除数为 0、连续按运算符、连续运算、计算完成后继续输入、退格删空、
  重复小数点、小数点开头、前导 0、负数开方、0 取倒数

## 键盘操作

| 键盘 | 等价按键 |
| --- | --- |
| `0`～`9`（含小键盘） | 数字键 |
| `.` | 小数点 |
| `Backspace` | ←（退格） |
| `Delete` / `Esc` / `C` | C（全部清除） |
| `+` `-` `*` `/` | + - × ÷ |
| `=` / `Enter` | = |
| `%` | % |

键盘的 `*`、`/` 会先转换成按钮上的 `×`、`÷`，再调用与鼠标完全相同的 `inputXxx()` 函数，
因此两种输入方式共享同一个 `CalcState` 状态机。

## 代码结构

| 文件 | 说明 |
| --- | --- |
| `mainwindow.ui` | Qt Designer 界面：表达式栏、显示框、6×4 按键网格 |
| `mainwindow.h` | `CalcState` 输入状态机、鼠标与键盘共用的处理函数声明 |
| `mainwindow.cpp` | 计算逻辑、边界处理、`keyPressEvent()` 键盘事件 |
| `style.qss` | 界面样式表（数字键、运算符、等号、清除键的配色与圆角） |
| `style.qrc` | 把 `style.qss` 打包进 Qt 资源，运行时用 `:/style.qss` 加载 |
| `Lab1.pro` | qmake 工程文件 |

关键点：

- 槽函数 `on_<对象名>_<信号名>()` 由 `setupUi()` 中的 `connectSlotsByName()` 自动连接，
  构造函数里**不要**再手动 `connect()`，否则一次点击会触发两次（退格一次删两位就是这样产生的）。
- 显示框 `readOnly` 且所有按键 `setFocusPolicy(Qt::NoFocus)`，窗口 `StrongFocus`，
  保证键盘事件统一由 `MainWindow::keyPressEvent()` 处理。

## 编译运行

用 Qt Creator 打开 `Lab1.pro`（Qt 6，MinGW 或 MSVC 均可）直接构建运行。
使用 MSVC 时工程已经加了 `/utf-8`，避免源码里的中文乱码。
